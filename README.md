# Casalto · Administración de arriendo

Front end en React + TypeScript + Tailwind (Vite). Sin backend: los datos viven en `localStorage` (`src/api.ts`).

    npm install
    npm run dev

Cuentas de prueba: `cliente@casalto.cl / cliente123` · `admin@casalto.cl / admin123`.
Para conectar un backend, reemplazar las funciones de `src/api.ts` por llamadas `fetch`.
